Study Journey JAPAN Ver.1.9.0 Official Release

主な追加機能
- 登録時に重複しないStudy Journey IDをApps Script側で自動発行
- パスワードなしで、IDだけを使ったログイン
- スマホ・パソコン・タブレット間のクラウド同期
- 同期対象：累計学習時間、週間学習時間、日別記録、カレンダー、ストリーク、各種ポイント、現在地、取得バッジ数、バッジ取得履歴、ニックネーム等
- プロフィール画像は同期せず、端末ごとに設定
- 既存利用者は現在のIDをそのまま利用可能
- Ver.1.8.5 R3の更新通知機能を継承

導入手順（重要）
1. GitHub Pages側のファイルを、このフォルダの内容で上書きしてPushします。
2. Google Apps ScriptのコードをAppsScript_Code.gsの内容ですべて置き換えます。
3. Apps Scriptを「新しいバージョン」として再デプロイします。
4. 新しいウェブアプリURLが発行された場合は、app.js先頭のAPI_URLをそのURLへ変更して再Pushします。
5. Apps ScriptでsetupSheetを一度実行し、権限を許可します。

注意
- パスワードがないため、IDを知っている人はその記録を開けます。氏名など重要な個人情報は登録しない運用を推奨します。
- 同じIDを複数端末で同時に動かすこと自体は可能ですが、タイマーの完全なリアルタイム共有ではありません。停止時・起動時にクラウドへ反映します。
- 既存ユーザーの取得バッジ履歴は、初回同期時に累計学習時間から自動補完されます。
