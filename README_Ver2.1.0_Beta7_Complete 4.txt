Study Journey JAPAN Ver.2.1.0 β7 Complete

MISSION機能を実装しました。

【操作】
- 1回転目・2回転目・3回転目のボタンを直接タップできます。
- タップするたびに理解度が循環します。
  未設定 → △ → ○ → ◎ → 未設定
- 理解度を設定すると同時に🔥解答済みになります。
- 問題名をタップすると、次の未解答回転を🔥解答済みにします。
- すべて解答済みの場合は3回転目を未解答へ戻します。

【保存】
- 問題ごとの🔥、理解度、3回転の状態を端末内に保存します。
- お気に入りも保存します。

【進捗】
- MISSION上部に、1回以上解答した問題数・総問題数・達成率を表示します。
- Chapterごとの進捗も表示します。

【ポイント】
- △を初めて付けたとき：+5pt
- ○を初めて付けたとき：+10pt
- ◎を初めて付けたとき：+20pt
- 同じ問題の3回転をすべて完了：+100pt
- 一度獲得した理解度ポイントとコンプリートポイントは重複加算しません。

【β版の注意】
- β7では操作確認を優先し、MISSION記録は端末内保存です。
- Apps Scriptの変更はありません。
- 正式版ではなくStudyJourneyJAPAN-Betaへ上書きしてください。
