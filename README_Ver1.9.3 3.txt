Study Journey JAPAN Ver.1.9.3 Official Release

更新内容
- Home画面のTotal Pointsの下に「ポイントランク〇位」を追加
- ポイントランクは、参加者全員の累計ポイントを基準に計算
- 同点の場合は同順位
  例：1位、2位、2位、4位
- Friends一覧の順番は、従来どおり「今週の勉強時間」順
- アプリ起動時およびFriends更新時に最新順位を反映

ポイントに含まれるもの
- 累計学習ポイント
- メダルポイント
- 連続学習ポイント
- エールポイント

1. GitHub側をVer.1.9.3の内容で上書きし、Commit・Push
