Study Journey JAPAN Ver.2.0.7 Official Release

主な内容
- APP VERSION：2.0.7
- 「🚀 最新バージョンで旅をする」ボタンを、
  「プロフィールを更新」と同じ濃い緑色・白文字に統一
- 更新後：
  「✅ 最新版に更新しました！」
  「Ver.2.0.7になりました。新しい旅をお楽しみください！」
- 最新版の場合：
  「✅ 現在、最新版です！」
  「Ver.2.0.7で旅をしています。」

更新方法
1. ZIPを解凍
2. 解凍フォルダの中身をGitHub管理フォルダへ上書き
3. GitHub DesktopでCommit
4. Push origin

Google Apps Scriptの再デプロイは不要です。
