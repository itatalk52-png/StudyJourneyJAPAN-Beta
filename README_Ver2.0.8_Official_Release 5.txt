Study Journey JAPAN Ver.2.0.8 Official Release

更新後のプロフィール画面を改善しました。

変更内容
- アップデート完了後、空欄の「参加者登録」画面を表示しないよう修正
- 登録済みのアイコン、ニックネーム、学部、学科、メールアドレス、IDを表示
- 登録済みユーザーには「プロフィール確認」と表示
- 「プロフィールを更新」ボタンに加え、
  「プロフィールはそのまま」ボタンを追加
- 「プロフィールはそのまま」を押すと、登録内容を変更せずHome画面へ戻る
- Version 2.0.8へ更新
- Service Workerのキャッシュを更新

既存のプロフィール、学習時間、ポイント、バッジは削除されません。
Google Apps Scriptの再デプロイは不要です。
