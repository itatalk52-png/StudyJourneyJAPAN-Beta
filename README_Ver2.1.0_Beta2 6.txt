Study Journey JAPAN Ver.2.1.0 β2

β1からの修正内容

1. Home画面・Timer画面のMISSIONボタン
- より薄いシャンパンゴールドへ変更
- STARTボタンより縦幅を短く調整
- 「（商業簿記）」「（工業簿記）」の括弧を削除
- COM. MISSION / IND. MISSIONのMと日本語の左端を揃える
- 行間、余白、影、文字間を調整し、すっきりしたデザインへ変更

2. MISSION画面
- 問題ごとの1〜5回目ボタンを直接押せるよう修正
- 押した回数を選択した状態で記録画面を開く
- 記録済みの回数を押すと、その理解度を表示して変更可能
- 問題名部分を押した場合は、次の未記録回数を自動選択

3. オフライン対応
- 日本一周マップ
- バッジ画像
- アイコンなどの静的画像
- MISSION一覧
- アプリ本体の主要ファイル

をService Workerが初回利用時に端末へ保存します。
初回の保存には画像数に応じて時間と通信量が必要です。
保存後は、通信が不安定な場所でも画面や画像を表示しやすくなります。
ランキング同期やサーバーへの記録送信など、オンライン接続が必要な機能は通信環境が必要です。

- これはβ版です。正式版のStudyJourneyJAPANには上書きしないでください。
- GitHub DesktopではStudyJourneyJAPAN-Betaを選択して導入してください。
- Apps Scriptのコード変更はありません。
