Study Journey JAPAN Ver.1.8.5 Official Release R3

追加機能
- 新しいバージョンを検知すると、アプリ内に更新確認ポップアップを表示
- 「今すぐ更新」を押すと最新版へ切り替えて自動再読み込み
- 「あとで」を押すと、そのまま現在の画面を利用可能
- アプリを開いた時、再び前面に戻した時、1時間ごとに最新版を確認
- 学習時間、プロフィール、各種記録は更新後も保持
- GitHub Pagesの同じURL・ホーム画面ショートカットのまま利用可能

重要
R3への最初の更新時だけは、旧版に更新通知機能がまだ入っていないため、
利用者によっては一度アプリを終了して再起動する必要があります。
R3以降の更新では、更新ポップアップが表示されます。

Apps Scriptの変更はありません。
