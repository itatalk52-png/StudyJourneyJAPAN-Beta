Study Journey JAPAN Ver.2.1.0 β3

β2からの主な変更

1. Home画面のMISSIONボタン
- 高さをβ2のおよそ3分の2へ縮小
- STARTボタンと同じような横長の丸いピル形状へ変更
- シャンパンゴールドの色味は維持
- COM. MISSION / IND. MISSION と日本語の配置を引き続き左揃え

2. Timer画面のMISSIONボタン
- 横幅を小さくして中央配置
- COM. MISSION / IND. MISSIONを少し大きく、太字に変更
- Home画面と同じ丸いピル形状へ変更

3. MISSION画面
- 1・2・3・4・5の表示を
  1回転目・2回転目・3回転目・4回転目・5回転目へ変更
- 各回転ボタンを押して記録可能
- 登録後、一覧に🔥と理解度（△・○・◎）を表示
- 登録済みの回転を押すと理解度を変更可能

4. オフライン対応
- β2で導入した、日本一周マップ・バッジ・アイコン・MISSION一覧等の初回キャッシュを継続
- Service Workerのキャッシュ名をβ3用に更新

導入時の注意
- 正式版ではなく、GitHub DesktopのStudyJourneyJAPAN-Betaへ上書きしてください。
- Apps Scriptの変更はありません。
